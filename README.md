# 🐾 Adote Um Focinho

## 📚 Project Context

**Project Type:** Final Assignment for Programming Language II Course
**Education Level:** High School Technical Informatics - 3rd Year

## 🌟 Objectives

Develop a web-based pet adoption platform to:
- Apply programming skills
- Create a technological solution for social impact
- Demonstrate web development capabilities

## ✨ Features

- 📋 Pet adoption listings
- ➕ New animal registration
- 🌐 Dynamic JavaScript and AJAX interface
- 🔧 Full CRUD operations
- 📸 Pet image uploads

## 🛠 Setup and Installation

### Requirements
- PHP 8.2+
- MySQL database
- Apache server (XAMPP, WAMP)

### Installation Steps
1. Clone repository
2. Configure database
3. Start local server
